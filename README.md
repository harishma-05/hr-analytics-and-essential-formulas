# 📊 HR Analytics – Employee Data Analysis

## 📌 Project Overview

This project focuses on Human Resource Analytics using Microsoft Excel. It analyzes employee data to understand workforce characteristics, salary distribution, employee performance, attendance, attrition, and promotion status.

The project helps HR professionals make data-driven decisions and improve workforce management.

## 🎯 Objectives

* Analyze employee demographics and workforce distribution.
* Identify department-wise and designation-wise employee details.
* Understand salary structures and annual compensation.
* Evaluate employee performance and attendance.
* Analyze employee attrition and promotion status.
* Support HR decision-making through data analysis.

## 📂 Dataset Information

The project contains employee information for **200 employees**.
